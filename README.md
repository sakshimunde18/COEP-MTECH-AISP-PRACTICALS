# 📷 DIVP Lab – Digital Image and Video Processing

The experiments cover fundamental concepts of **digital image processing, image enhancement, filtering, frequency-domain processing, segmentation, and related techniques** using Python.

## 📚 Experiments

| No. | Experiment                              | Description                                                   |
| --- | --------------------------------------- | ------------------------------------------------------------- |
| 01  | Image Representation & Basic Operations | Read, display, resize, rotate, crop and transform images      |
| 02  | Image Enhancement                       | Improve image quality using intensity transformations         |
| 03  | Histogram Processing                    | Histogram generation, equalization and matching               |
| 04  | Spatial Domain Filtering                | Smoothing and sharpening using spatial filters                |
| 05  | Noise Removal                           | Add different types of noise and remove them using filters    |
| 06  | Frequency Domain Processing             | Fourier Transform and frequency-domain filtering              |
| 07  | Image Restoration                       | Restore degraded or noisy images                              |
| 08  | Image Segmentation                      | Segment images using thresholding and related techniques      |
| 09  | Edge Detection                          | Detect edges using operators such as Sobel, Prewitt and Canny |
| 10  | Morphological Processing                | Perform dilation, erosion, opening and closing                |
| 11  | Color Image Processing                  | Perform processing and enhancement of color images            |
| 12  | Video Processing                        | Read, process and analyze video frames                        |

## 🎯 Objectives

* Understand the fundamentals of digital image processing.
* Perform basic image manipulation and enhancement.
* Analyze image histograms.
* Apply spatial and frequency-domain filters.
* Remove noise from digital images.
* Detect edges and segment images.
* Understand morphological image processing.
* Perform basic color and video processing.
* Implement image-processing algorithms using Python.
